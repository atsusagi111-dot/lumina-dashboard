# README 更新 手順書

README は「これを読めば開発内容がすべて分かる」状態を保つ。**タスク完了のたびに**、コミット前に以下を確認する。

## 毎タスク共通のチェックリスト
- [ ] 「開発の進捗」表の該当 Task を ✅ にし、完了日を書いた
- [ ] 新しく増えたフォルダ・主要ファイルを「ディレクトリ構成」に追加した
- [ ] 新しい環境変数があれば `.env.example` に追加した（README はキー名を列挙せず `.env.example` を参照する）
- [ ] 新しい `pnpm` スクリプト（`test:analysis` など）があれば「コマンド一覧」に追加した
- [ ] 初心者が詰まりそうな点を「トラブルシューティング」に追加した
- [ ] 専門用語には一言の補足を付けた
- [ ] 画面が増えた場合はスクリーンショット（`docs/images/`）を追加した

## 各タスクで必ず書く項目
| Task | README に追加する内容 |
| --- | --- |
| 0 | 開発ルール（サイクル・worktree・hooks の説明）、事前準備一覧 |
| 1 | セットアップ手順（`pnpm install` → `pnpm dev`）、ブランドカラー |
| 2 | Supabase の作り方、migration の当て方、RLS の説明、ログイン手順 |
| 3 | **クライアント向けのシート共有手順**、列の仕様、エラーメッセージ例 |
| 4 | KPI の一覧（定義は SKILL へのリンク）、正解値との一致確認方法 |
| 5 | 画面イメージ、レスポンシブの確認方法 |
| 6 | AI 分析の仕組み、`pnpm test:analysis`、§10 に 1 回あたりのコストを追記 |
| 7 | CI の流れ、Vercel 連携手順（環境変数の登録含む） |
| 8 | 月額コスト試算（5,000 円以内）、Phase 2 ロードマップ、納品チェックリスト |

## 目次の順序
README の目次（1〜12）の順序は固定。節を増やすときは末尾ではなく該当節の中に追加する。
