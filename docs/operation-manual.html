LUMINA 売上分析ダッシュボード 運用マニュアル

https://lumina-dashboard-seven.vercel.app

月次運用フロー（所要 30 分）

  1. スプレッドシートに先月分の売上を貼り足す（1 枚のシートに全期間を貯める。月ごとにシートを分けない）
  2. ダッシュボードにログインし、上部メニューの「取り込み」を開く
  3. スプレッドシートの URL を貼り付けて「取り込む」（URL の代わりにシート ID を貼っても可）
  4. 「○○件を取り込みました」の表示を確認。問題があった行は、何行目の何が原因かが一覧表示される
  5. ダッシュボードで対象の月を選び、「AI 分析を生成」を押す（10 秒ほどで表示）
  6. 画面のスクリーンショットを社内報告へ（AI コメントは下書き。数字は画面の値が正）
同じシートを何度取り込んでも、売上が二重に数えられることはありません（集計対象はいちばん新しい取り込み 1 件のみ）。AI 分析は月ごとに保存されるため、取り込み直しても過去月の分析は消えません。

スプレッドシートのフォーマット

列名（1 行目に記載）必須内容・書き方
order_date必須注文日。YYYY-MM-DD / YYYY/M/D のどちらも可（例：2025-11-03、2025/11/3）
customer_id任意顧客 ID。空欄はリピート率の計算から除外（売上・粗利には含む）
product_name必須商品名
category任意カテゴリ。空欄は「未分類」にまとめる
sku任意品番。空欄は SKU ランキングから除外（売上には含む）
quantity必須数量。半角の整数（1e3 や全角数字は不可）
revenue必須売上（円）。19800 / 19,800 / ¥19,800 のいずれも可
cost必須原価（円）。同上
列はこの順・この名前で 1 行目に置いてください。完全に空の行は自動で読み飛ばします。
シートは事前に、取り込み画面に表示されているサービスアカウントのアドレスに「閲覧者」で共有しておく必要があります（初回のみ）。文字コードの設定は不要です。

トラブル対処

症状対処
「スプレッドシートを開けませんでした」URL が正しいか、サービスアカウントに「閲覧者」で共有済みかを確認
全行が読み込まれない／列が違うと言われる1 行目の列名を確認（上表の名前と完全一致が必要）。直らなければサポートへ連絡
「○件の問題が見つかりました」と出て保存されない仕様です。1 行でも問題があれば何も保存しません。表示された行を直して再取り込み
症状対処
AI コメントが出ない／生成に失敗する時間をおいて再実行（API の一時障害の可能性）。翌日も続くならサポートへ連絡
画面に「売上データを取り込みましょう」と出る取り込みはログインした本人のデータだけが見えます。取り込んだ本人のアカウントでログインしているか確認
数字が思ったより多い／少ない取り込み画面の履歴で、最後に取り込んだシート名と件数を確認
データを扱ううえでの注意：AI には集計結果だけを送っており、顧客 ID や売上明細は外部に送信していません。画面は取り込んだ本人だけが閲覧できます（他の方へはスクリーンショットで共有してください）。
